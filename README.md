**Дисциплина:** Жизненный цикл разработки программного обеспечения

## Описание проекта

Приложение на C++ для управления списком задач: добавление, удаление, просмотр и отметка выполненных задач. Данные хранятся в оперативной памяти (в дальнейшем возможно сохранение в файл).
